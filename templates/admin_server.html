Server & Queue

Real generation uses the official WanGP Python API (session.submit_task from API.md). For a remote WanGP MCP server, set the MCP URL only (e.g. http://YOUR_SERVER:8080/mcp). Media is uploaded via Gallery transfer; local install path is optional fallback on the same machine.

WanGP Streamable HTTP MCP endpoint. Tools: wangp_generate, wangp_get_job, wangp_list_models, … Launch with python wgp.py --mcp --mcp-transport streamable-http --mcp-host 0.0.0.0 --mcp-port 8080

If MCP Gallery download is empty, the app fetches filename from this URL. On the WanGP PC run e.g. python -m http.server 8090 --directory C:\AI-Tools\Wan2GP\outputs then set this to http://WANGP_IP:8090. Required if your WanGP build has no gallery tools.

Uploads input files over HTTP to scripts/inputs_server.py running on the WanGP host — no shared/mounted folder needed between the two machines. On the WanGP PC run e.g. python scripts/inputs_server.py --directory C:\AI-Tools\Wan2GP\inputs --port 8091 then set this to http://WANGP_IP:8091. Takes priority over the mounted-folder fields below when set. Required for i2i / i2v / ia2v / v2v when the WanGP build lacks wangp_create_gallery_upload and genai isn't on the same machine as WanGP.

Must match the --token value passed to inputs_server.py, if any.

Only used when no upload URL above is set. Must be a path as this server sees it that is actually a mounted share reachable from both machines — e.g. \\\\WANGP_IP\\wangp-inputs on Windows, or an SMB/NFS mount point on Linux. If genai and WanGP are on different hosts and nothing is mounted here, this will fail with "not accessible or writable" — use the upload URL above instead.

Pose/depth guides are sent as letters in video_prompt_type. The alphabet has changed between WanGP releases — override here if pose control picks the wrong preprocessor. Leave blank for defaults.

Only used with the mounted-share fallback above. The same folder as WanGP sees it. Files are copied to the folder above, then this path is sent.

Folder that contains wgp.py and shared/api.py. Same machine as this app.

Used when Model is Auto on t2v / i2v / ia2v / v2v / p2v jobs.

Used when Model is Auto on t2i / i2i jobs.

Prefills the Advanced field. Easy mode uses its preset's value.

Preselected for everyone in Easy mode. Broadcast needs significant VRAM at 1080p — test one job before making it the default for the team.

Optional. Not required if only MCP is running — results are fetched via wangp_list_gallery + wangp_create_gallery_download.

Job queue

Control how many generations run at once. Extra jobs wait in queue when enabled.

If disabled and the limit is full, new jobs are rejected (HTTP 429) instead of waiting.

Official API (API.md)

from shared.api import init
session = init(root=Path("/path/to/Wan2GP"))
job = session.submit_task({
  "model_type": "ltx2_22B_distilled",
  "prompt": "...",
  "resolution": "1280x704",
  "num_inference_steps": 8,
  "video_length": 97,
})
result = job.result()  # result.generated_files
